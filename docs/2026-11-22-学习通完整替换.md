## 范围

按用户澄清，本次不保留 Android 原有学习通扫码登录、随堂活动采集及旧学习通任务数据；用 xxt-assistant 的只读清单能力重做 Android 学习通子系统。这里是对其采集与解析流程的 TypeScript/Capacitor 移植，不是把 Python 桌面程序、桌面 UI、悬浮窗或后台通知整个仓库嵌入 APK。学校通知、首页、课表和底栏仍属于科小喵。

参考项目提供账号密码登录、课程列表、课程作业及有限详情读取、未完成考试、通知中心未读项及同步行为。本次 Android 实现复用了这些流程思想，按 Android 现有网络和 Keystore 能力实现；没有移植参考项目的 Windows UI、驻留提醒，也没有移植原应用随堂活动接口。

## 代码改动

- `apps/web/src/android/auth.ts`：采用学习通账号密码登录及独立会话；WebView 不再走旧扫码登录。选择记住时凭据通过 Android Keystore 插件单独保存，密码不写入 `localStorage`。
- `apps/web/src/android/lib/chaoxing-crypto.ts`：实现登录表单字段 AES 加密。
- `apps/web/src/android/lib/chaoxing.ts`：从所有发现课程读取作业/作业详情、未完成考试和未读消息；按账号与来源标识生成清单项；串行限速、课程/分类级错误隔离和缓存处理。详情每轮有数量/时长上限，并按缓存时间刷新。
- `apps/web/src/android/lib/parse.ts`：对应移植课程、作业列表与详情、考试和未读消息解析。
- `apps/web/src/android/api.ts`、`apps/web/src/App.tsx`、学习任务界面：迁移旧缓存模式并清理随堂活动入口/类型；账号更换或退出会清理当前账号结果。教务 VPN 与学习通会话分离。
- Android 插件 `SchoolCredentialsPlugin.java`：为学习通凭据提供独立 Keystore 存储和清除入口。

用户此前询问过两个月范围；初版把它误实现成硬截断，这与参考项目 README 所述“只看未完成项、已过期/已提交不显示”不等价。2026-11-22 已从源码移除此两个月截断。参考项目没有随堂活动采集，因此 Android 不再显示旧随堂活动。考试与未读消息按其各自类型展示，不混入校园通知。

## 对照后发现并修正的行为差异

- 初版作业状态表漏掉“已逾期/已截止/已结束/已过期”，会把部分应归入完成的作业留在待办；现在已加入完成状态集合。
- 初版考试只依据作答状态过滤；现在同时检查考试状态，并用考试开始时间和时长排除已结束场次，进行中的状态优先保留。
- 初版 Android 收集器另外隐藏两个月以前的待办；该限制已移除，避免超出参考项目语义。
- 这些修正已通过离线解析用例和 TypeScript 检查，但本机当前只有 Java 11，Android Gradle 插件要求 Java 17，故新源码尚未重打进 APK。设备中已安装 APK 仍是上一版 0.1.9，不能视为包含本节修正。
