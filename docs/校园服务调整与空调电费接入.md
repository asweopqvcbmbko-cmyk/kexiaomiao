# 校园服务调整与空调电费接入记录

## 入口和迁移

Android 和 Electron 已移除学习通登录、采集、同步、专用解析和服务桥接。旧页面调用由数据门面返回停用或空值，页面本身未修改。原本的教务课表、考试与倒计时、校园通知、校园卡余额、智惠充电桩继续调用原服务。

Android 启动读取缓存时清理旧学习通 Cookie、Keystore 凭据与待发送通知。前端启动移除旧任务快照、本地标记与提醒记录。Electron 第一次启动时清理旧任务文件、加密会话文件和独立浏览器分区。迁移均不读取或上传旧凭据，失败时下次重试。现有页面仍可能初始化空的本地标记，学习通服务不再读取或写入任务缓存。

## 空调电费

数据门面新增 data.airconRoom()、data.saveAirconRoom(room) 和 data.airconElectricity()。Android 按本机保存的校区、楼栋、房间号处理查询。成功结果区分金额（元）、剩余电量（kWh）、校方更新时间和本机查询时间。未绑定房间、没有可用数据源、需要登录、平台确认无数据和查询失败分别返回不同状态。

已查本机主工程、历史工程、原型和历史任务记录。找到的旧空调电费展示为模拟数据，未发现真实查询代码或脱敏响应。校方后勤指南只确认「我i科大」App 的空调电费入口（https://hgc.haust.edu.cn/info/1050/9054.htm）。学校查询适配器待确认实际地址、认证和返回格式，目前返回 provider_unavailable。未使用校园卡余额推算电费。

## 核验

使用 npm run build（含 tsc --noEmit）核验前端，使用 node --check 检查 Electron 主进程和 preload。未用真实宿舍或教务账号复验，未安装新包到设备。
