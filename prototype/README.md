# 三版界面演示（第二轮）

上一轮的 A/C 已删除，B 的毛玻璃质感作为底色保留下来，但**页面排布重做了三版**。

三份 HTML + 一份共享数据：

| 文件 | 作用 |
|---|---|
| `index.html` | 三版并排对照 + 差异表（双击这个开始） |
| `d1.html` | **D1 · 周表优先**：课表是主角，7 天概览条 + 按天分组大卡 |
| `d2.html` | **D2 · 宫格入口**：2×4 功能宫格，每格带实时数字；课表以网格为主 |
| `d3.html` | **D3 · 信息流**：一页读完今天所有事；课表用日视图时间轴 |
| `data.js` | 三版共用的真实数据（2026-11-05 本机缓存），改一处三版同步 |

## 怎么看

1. **电脑**：双击 `index.html`，三版并排。
2. **手机 / MuMu**：`http://<局域网IP>:5184/index.html`（当前 `http://10.111.36.58:5184/`）。
   模拟器建议 `adb reverse tcp:5184 tcp:5184` 后开 `http://127.0.0.1:5184/d1.html`。
3. 直达某页：`d1.html#table`、`#task`、`#exam`、`#notice`、`#charger`、`#settings`、`#grid`（课表网格视图）。

## 课表这轮到底改了什么

上一轮的问题：7 天挤在 390px 里，课名只能放两个字，周日还被切掉。

这一轮把「网格」降级成备选视图，主视图换成三种可读排布：

- **D1**：顶部一条**7 天概览条**（每天：周几、几门、所有课名短名），下面**按天分组**成大卡。
  一张卡里 = 节次 + 全名 + 教师 + 教室；**撞课的两门并排显示**，各自可以点开看自己的详情。
- **D2**：网格铺满 7 列（22px 节次列吸顶），格内 2–3 行课名 + 压缩后的教室号；
  撞课的那一格右上角有黄点，点黄点直接打开另一门。另有「按天」视图。
- **D3**：**日视图时间轴**——一行一门课，信息最宽松；下面补「本周其他天」摘要，避免只看一天。

配色也换了规则（学自 sleepy）：**只按课名散列分配色相，饱和度和明度全局固定**，
并避开主题蓝与补色带，所以一屏里颜色不少但不刺眼，也不会跟"逾期红"混在一起。

## 兼容红线（做 APK 时会被卡）

MuMu 实测 **Android 15 / x86_64 / 系统 WebView 110**，所以：

- ❌ 不用 CSS 嵌套（`&:before`，参考项目源码大量用，WebView 110 会整段失效）
- ❌ 不用 `color-mix()`、`oklch()`（Chrome 111+）
- ✅ 可用 `backdrop-filter`、`:has()`、`@container`、`100dvh`
- 玻璃效果仍需**优雅降级**：检测不到 `backdrop-filter` 就退成半透明实色
