校园助手 · 三版界面演示（第二轮）

三版用的是同一份真实数据（你本机 2026-11-05 的课表 / 学习通 / 考试 / 通知 / 充电桩 / 校园卡缓存）， 并且桌面版的模块一个都没少：今日、课表、考试、通知、任务、充电桩、设置全都在。 课表这轮是重点：不再是挤成一团的格子，而是先给「7 天概览」「按天分组」「日视图时间轴」这类可读排布，网格只作为备选视图。 手机或模拟器直接打开 d1.html / d2.html / d3.html；各版可用 #table #task #notice #charger #exam #settings 直达某页。

课表能看多细全名 + 教师 + 教室 + 节次，撞课两门都在格内 2–3 行课名 + 教室，撞课有角标可单独点一行一门课，信息最宽裕
找功能要几步底栏 3 个 + 「更多」宫格，2 步首页 1 步直达任意模块信息流里滚，或点「查看全部」
适合谁每天先看一眼课表的人功能用得多、想快速跳转的人只想打开就知道「今天要干什么」的人
缺点首页较长，功能藏在「更多」首页是入口不是内容，要多点一下信息流长了要靠锚点跳
这轮补齐的桌面版细节（三版都有）：课表撞课时另一门课也能单独点开看详情 · 任务每行「✓ 完成」，点过就记在本机，刷新/重开不再出现（设置里可清除）· 周次可切、可「回到本周」· 通知按来源筛选、点开标已读 · 充电桩 13 个点位的空闲/总数/充电中/距离 · 8 场考试与倒计时 · 校园卡余额 · 更新于时间与刷新按钮。
